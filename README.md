# Sajjel

Sajjel is a full-stack web application built to practice and validate modern frontend architecture while keeping the backend cleanly separated. The project focuses on building a production-ready UI system with realistic data flows before backend completion.

## Tech Stack

### Frontend
- React 19 + TypeScript
- Vite
- Tailwind CSS
- shadcn/ui (Radix UI)
- TanStack React Query
- TanStack Table
- React Router
- MSW (Mock Service Worker) for API mocking
- Axios

### Backend
- Laravel 12
- PHP 8.2
- JWT Authentication
- Laravel Sanctum
- SQLite (development)
- RESTful API design

## Key Highlights

- **Advanced UI system** built with Tailwind CSS and shadcn/ui, focusing on consistency, reusability, and accessibility
- **Frontend–backend separation**: developed the frontend independently using a fully mocked API layer
- **Mock Service Worker (MSW)** used to simulate real backend behavior, enabling parallel development
- **Scalable data layer** using TanStack React Query for caching, synchronization, and error handling
- **Clean architecture mindset**: components, hooks, and data logic are clearly separated
- Backend prepared with authentication, API structure, and queue-ready setup

## Why This Project

Sajjel was created to:
- Go deeper into modern frontend tooling and patterns
- Practice building realistic frontend systems without backend dependency
- Improve UI/UX quality, state management, and API integration workflows
- Simulate real-world team development conditions

## Status

The project is under active development and serves as a foundation for further backend integration and feature expansion.
